## Agent 内部组件（逻辑架构）

> 仅描述逻辑关系，不包含部署/运行时细节。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ Agent Handler (业务入口)                                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│  1) 解析请求 / 意图                                                           │
│  2) 选择 Tools 或 Adapter 操作路径                                            │
│  3) 组装执行结果 (ExecutorResult)                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ Tools Layer (功能调用层)                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│  - 工具注册与声明 (get_tools)                                                 │
│  - 工具调用路由 (tool_name → handler)                                         │
│  - 危险操作标记 (dangerous: true)                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ Adapter Layer (外部系统适配层)                                                │
├─────────────────────────────────────────────────────────────────────────────┤
│  - 统一封装外部系统 (K8s / DNS / CI/CD / Git 等)                               │
│  - 处理认证、连接、错误标准化                                                   │
│  - 返回规范化数据结构                                                          │
└─────────────────────────────────────────────────────────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ Permission & Policy (权限策略层) [设计层 - 未实现]                              │
├─────────────────────────────────────────────────────────────────────────────┤
│  - Agent 安装/启停状态校验 ✓                                                   │
│  - Remote Executor 的认证上下文 (auth_context) ✓                              │
│  - RBAC / ABAC 细粒度权限 (计划中)                                             │
│  - 危险工具审批流程 (计划中)                                                    │
│  - 变更审计 (计划中)                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

### 组件说明

| 组件 | 职责 |
|------|------|
| **Agent Handler** | 业务入口，负责意图解析与结果组织 |
| **Tools Layer** | 提供标准化工具接口与声明，实现 tool 路由 |
| **Adapter Layer** | 对外部系统的统一封装与错误标准化 |
| **Permission & Policy** | 权限与安全边界，决定是否允许执行 |

### 逻辑执行路径

```
Request → Agent Handler
         ├─ Tool Call Path → Tools Layer → Adapter → Result
         └─ Direct Path    → Adapter / Internal Logic → Result
```

## 关键逻辑摘要（逻辑层级）

- **调用入口**：Client → API Gateway → ExecutorRouter
- **执行分发**：BuiltinExecutor（内置） / RemoteExecutor（第三方）
- **意图分配**：仅在 `nexusops.chat` 内部通过 LLM 工具调用完成
- **权限边界**：安装状态/认证上下文/危险工具审批（逻辑层）
